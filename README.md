# Sufwan Saleem – Portfolio (GitHub Pages)

## Live karne ka tareeqa
1. github.com par login karein (account: muhammadsufwan).
2. New repository banayein, naam bilkul yeh rakhein: `muhammadsufwan.github.io` (Public).
3. "uploading an existing file" par click karein aur is folder ki SAARI files/folders drag & drop karein
   (index.html, style.css, script.js, .nojekyll, assets folder).
4. "Commit changes" dabayein.
5. Settings > Pages > Source: "Deploy from a branch", Branch: `main` / `(root)` > Save.
6. 1-2 minute baad site live: https://muhammadsufwan.github.io
